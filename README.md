# Unsent: The Micro-Confession Sprint — entry

## About this entry

This entry is a confession that only works because of who it is addressed to.
The message admits a small, old theft of blame: a broken garage window that a
younger brother was grounded for, eleven years ago, while the person who
actually broke it stayed quiet and let the punishment land on the wrong kid.
It is written the way it would really be typed — all lowercase, no polish, no
greeting and no sign-off — because it was never meant to survive being read
back. The reason it stayed in drafts is the last clause: sending it to the
brother is the easy part, but the confession only counts if their dad hears
it too, and the writer still cannot be the one to tell him. Swap the To: line
for anyone else and the whole thing collapses — a parent would need a
different apology, a friend would have no stake in the grounding — which is
exactly the interdependence the brief asks for. The program keeps the text
honest to the gate as well: two lines only, the message under 200 characters,
the whole file under 260, and a To: line that names a relationship rather
than a real person.

## Running it

`python3 main.py` writes the entry to `/output/entry.txt` (override the
directory with `ENTRY_OUTPUT_DIR`) and refuses to write anything that
breaks the gate.
